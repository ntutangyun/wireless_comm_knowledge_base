## Summary (EN)

On 2026-11-17 Iridium Communications announced (press release from McLean, Virginia) that it has activated Iridium NTN Direct, a satellite service built on NB-IoT and direct-to-device (D2D) standards. Iridium describes it as the first 3GPP standards-based service delivered from space with worldwide reach; the claim is Iridium's own and was not independently checked here. The service runs on Iridium's existing low-Earth-orbit constellation using globally coordinated L-band spectrum and works with compatible NB-IoT chipsets, which Iridium says simplifies integration for mobile network operators, chipset makers and device makers. The release lists consumer uses (wearables, personal safety, emergency messaging) and commercial/industrial uses (asset tracking, fleet management, logistics, connected vehicles, smart agriculture, utility metering, industrial monitoring, remote infrastructure). Named ecosystem partners are Nofence (integrating the service into its N3 livestock collars), Nordic Semiconductor (its nRF9151 is described as the first NTN module certified for the service, with a public firmware update planned for January 2027 so existing modules can support it without new hardware), and Altair Semiconductor, Deutsche Telekom IoT, Mlink Technology and Vodafone IoT. Coverage is described as available anywhere on Earth today, but initial availability varies and use in any jurisdiction depends on local authorization, regulations and service-provider conditions.

## Key technical points (EN)

- **Air interface / standards:** standards-based NB-IoT with D2D; compatible NB-IoT chipsets connect directly to the satellites. The release states no 3GPP release number (Iridium's product page, cited in an earlier KB entry, places the service in Release 19).
- **Spectrum and space segment:** existing Iridium LEO constellation; globally coordinated L-band. No specific band numbers, data rates, link budgets or pricing are given in the release.
- **Module ecosystem:** Nordic nRF9151 certified for the service; public firmware update planned for January 2027 so already-shipped modules can be enabled by software. Altair Semiconductor and Mlink Technology also named.
- **Operator/enterprise channel:** Deutsche Telekom IoT and Vodafone IoT named as partners; Nofence quoted on pole-to-pole livestock-collar use with the same NB-IoT protocol as cellular networks.
- **Availability caveats:** global coverage claimed, but initial availability varies by jurisdiction and depends on local authorization and service-provider conditions.
- **Not stated:** release number, band numbers, throughput, pricing, device volumes.

## Why it matters / what's new (EN)

This is the commercial-activation step that follows the 2026-09-10 Iridium / Deutsche Telekom IoT / Toyota voice-messaging demonstration already in the KB (2026-09-11_iridium-dt-toyota-ntn-direct-voice-messaging): the earlier entry covered a demonstration, this one records the service being switched on, together with the named module and partner list and the January 2027 firmware dependency for existing nRF9151 hardware. It is a standards-based NB-IoT service on an operating L-band MSS constellation rather than a new constellation, so it sits beside the KB's other D2D/NTN items as a different deployment route. Technical depth is limited: the release gives no data rates, release number or pricing.
