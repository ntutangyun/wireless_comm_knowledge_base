## Summary (EN)

SatNews (article dated 2026-10-11) reports that Kratos Defense & Security Solutions announced on 2026-10-08 an end-to-end, two-way data transmission over a "native, multi-vendor 5G New Radio Non-Terrestrial Network (5G NR NTN)", run as a flight-and-ground demonstration on a fully virtualized, software-defined ground architecture. Kratos supplied the OpenSpace Radio Access Network (the virtualized satellite base station handling RF signal processing and dynamic beam resource allocation); Druid Software supplied the Raemis 5G Core; GCT Semiconductor's GDM7275X 5G modem chipset served as the remote satellite-connected UE; KT SAT gave collaborative technical support. Signal processing runs as software on commercial off-the-shelf servers, using Digital Intermediate Frequency (DIF) standards to process digitized RF signals. The article does not name the satellite, operator or orbit, and gives no throughput, latency or other performance figures; it says the satellite industry is aligning with 3GPP Release 17 and 18 NTN standards.
