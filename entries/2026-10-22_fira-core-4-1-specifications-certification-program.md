## Summary (EN)

On 20 October 2026 the FiRa Consortium announced, via Business Wire, the release of the FiRa Core 4.1 Specifications together with an updated 4.1 Certification Program, described as advancing ultra-wideband (UWB) interoperability. The release lists three feature groups. First, enhanced Down-Link TDoA (DL-TDoA) for FiRa Untracked Navigation, adding coordinate-system and anchor-location encoding options, including floor identification without increasing message size; certification covers these options and cross-cluster synchronization. Second, expanded DS-TWR security certification, adding responder-specific sub-session keys and 256-bit key testing for Dynamic and Provisioned Scrambled Timestamp Sequence (STS). Third, extended ranging capabilities, with greater certification coverage for data transfer during DS-TWR and for One-Way Ranging Angle of Arrival (OWR AoA) measurements. The release also notes specification and program maintenance (clarifications, corrections, restructuring and test updates).

The announcement names private multi-floor indoor navigation (airports, malls, hospitals) as a target, alongside enterprise, automotive, industrial and asset-tracking deployments. The updated 4.1 Certification Program is available through FiRa Authorized Test Laboratories, where manufacturers and chipset vendors can submit products for Core 4.1 compliance testing to earn the FiRa Certified designation. FiRa President Sunil Jogi is quoted citing 256-bit cryptographic key validation, optimized DL-TDoA floor encoding and cross-cluster synchronization.

## Key technical points (EN)

- Release: FiRa Core 4.1 Specifications plus an updated 4.1 Certification Program, announced 20 October 2026.
- DL-TDoA for Untracked Navigation: new coordinate-system and anchor-location encoding options, with floor identification that does not increase message size; certification covers the options and cross-cluster synchronization.
- DS-TWR security certification: responder-specific sub-session keys; 256-bit key testing for Dynamic and Provisioned STS.
- Ranging coverage: certification extended to data transfer during DS-TWR and to OWR AoA measurements.
- Maintenance: clarifications, corrections, restructuring and test updates for readability and practical deployment.
- Availability: the 4.1 certification is offered through FiRa Authorized Test Laboratories; products passing earn the FiRa Certified designation.
- The release does not publish the specification text or test plans; those details are outside this announcement.

## Why it matters / what's new (EN)

The announcement is the consortium's own account of what changes at the certification level in Core 4.1: floor-aware DL-TDoA encoding for multi-floor venues, responder-specific sub-session keys with 256-bit STS key testing, and wider test coverage for DS-TWR data transfer and OWR AoA. It complements this knowledge base's earlier coverage of the FiRa plugfest programme and the FCC rulemaking, which concerned interoperability events and spectrum rules rather than the specification and certification content itself. Detailed behaviour of the new options will only be verifiable from the specification and test documents, which this release does not reproduce.
