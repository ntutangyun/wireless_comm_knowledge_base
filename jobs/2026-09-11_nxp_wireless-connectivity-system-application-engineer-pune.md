# Senior System and Application Engineer

**NXP** - Pune - posted 2026-09-02

## Posting (relevant sections, verbatim)

Overview
NXP’s Wireless Connectivity group is building the next generation of wireless chipsets for Automotive, Gaming, IoT, Industrial and Smart-Home devices.
These chipsets will define ultra-low power, high performance and low latency benchmarks for products that rely on Wi-Fi, BT/BLE and 802.15.4
We’re looking for a strong, self-driven and curious System & Application Engineer with a focus on SW.
Responsibilities
Design, implement and unit test for NXP’s Software Solution on Wi-Fi/Bluetooth/IoT solutions on existing as well as upcoming SoC
Involved in designing Software solutions for bug fixes for customer reported issues, adding enhancement to existing features etc
Debugging issues reported by customers as required on various platforms
Providing technical support to customers during their evaluation and integration of NXP’s Wireless Connectivity solutions
Working with Marketing, Sales and Field Application Engineers to understand customers use cases and requirements, and influence next generation products
Qualifications-
MS/ME/MTECH with 6+ years of experience in EE, CE, CS or equivalent is required
Strong experience in embedded systems, operating systems including RTOS, Linux operating systems, kernel internals
Experience with C programming and debugging is a must
Very good understanding on Networking components like TCP/IP
Having a background on Wi-Fi, Bluetooth, 15.4 protocol a significant advantage
Exposure to ARM processor architecture is required
Experience with SDIO/PCIe/USB bus interface is preferred
Need to work independently on tasks from understanding the requirements, to design, implementation and testing. Also need to work cross function teams
Effective interpersonal, teamwork, and communication skills
