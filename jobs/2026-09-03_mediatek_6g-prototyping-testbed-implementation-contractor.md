# MediaTek — 6G Prototyping & Testbed Implementation (Contractor)

## Job Description

Open-source implementation of 5G/NR or other physical layer on SDR platform, written in C and running on generic CPUs and GPU. Requires novel software computation algorithm, memory management, computing bus management for large data and real-time system task critical time and management. You will contribute to the improvement of the communication L1/PHY stack of OAI. Specifically, you will start working on the L1/PHY of the gNB:

- Support with the implementation of digital beamforming in the downlink
- Support with the integration of the OSC xran library in OAI, and test of the 7.2 interface
- Refactoring of the existing L1 code base towards a more efficient implementation, writing of tests

## Main Requirements and Qualifications

- Very strong C/C++ skills
- Very good knowledge of communication background
- Solid experience in RAN software development (L1 experience required, L2/L3 is a plus) and using SIMD intrinsics
- Very good understanding of Git SCM
- Experience with 5G/NR L1 implementations or cuda is a plus
- Strong analytical skills and problem-solving attitude
- Good interpersonal and teamwork skills to collaborate and work well with others

Category: Algorithm & Architecture. Experience: No Work Expe. Education: Bachelor's Degree.
