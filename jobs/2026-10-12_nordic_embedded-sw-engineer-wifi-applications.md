About the job

We are recruiting talented and experienced embedded software engineers to join the Wi-Fi Software Group, to further develop Nordic Semiconductor's Software Development Kits for our Wi-Fi products. The role can be tailored depending on your skills and experience.

You will be working on our nRF Connect SDK, Nordic's unified development framework, which is built around the Zephyr open-source RTOS. You will take part in open-source software development, focusing on building low-power Wi-Fi applications on Nordic Semiconductor's nRF Series devices.

This offer is for an experienced engineer, with good collaboration skills, a proactive mindset towards leveraging AI development tools, and a genuine interest in embracing new hardware and software solutions. Together with a group of competent, embedded SW engineers you will be working on platform software framework, reference designs, applications and samples, integrating a wide set of functionalities offered by Nordic's nRF Connect SDK on our current and future Wi-Fi products. Your code has a chance to be used by millions of people globally.

Key responsibilities:
- Development of applications based on Nordic Semiconductor technologies with a core focus on Wi-Fi
- Supporting new Nordic hardware platforms by contributing to and maintaining SDK components and libraries, as well as porting and integrating reference applications and sample code in nRF Connect SDK
- Creating examples presenting our products' functionality and performance
- Ensuring high code quality by providing test and documentation of developed code
- Contributing to Zephyr Real-Time OS including development work on drivers and core components for Wi-Fi products
