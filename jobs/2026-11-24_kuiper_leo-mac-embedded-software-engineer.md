# Embedded Software Engineer, Leo MAC

**Amazon (Project Kuiper / Leo)** - US, WA, Redmond - posted 2026-11-21

### Summary (page text condensed by the fetch summarizer)

Embedded Software Engineer building firmware for LEO satellites and customer terminals on ground networks, within the LEO MAC software group of Amazon Leo. The role covers real-time embedded environments, RTOS and bare-metal systems, and cross-functional performance trade-offs.

### Key responsibilities

- Design, develop, integrate, and bring up LEO-MAC firmware components and drivers.
- Define multi-dimensional performance requirements (e.g., MIPS, memory bandwidth).
- Make performance and optimization trade-offs to meet end-to-end use-case requirements.
- Build component use cases and test cases, and debug code in the LEO embedded environment.
- Profile and execute code on RTOS and/or bare-metal systems.
- Define, document, test, and debug firmware-hardware interfaces.
- Contribute to defining the services and functionality of firmware subsystems.

### Basic qualifications

- 3+ years of professional non-internship software development experience.
- 2+ years of design or architecture experience.
- 1+ years developing large-scale, multi-threaded embedded or distributed systems in C#, C++, Java, or Perl.
- Bachelor's degree in Computer Science, Engineering, Mathematics, or a related field.
