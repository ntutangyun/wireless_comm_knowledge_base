Join Our Team

About this opportunity:
Want to take a challenge to shape a new world of communications?
Join Ericsson's Purpose Build RAN Layer 1 Software organization and help build the technology that powers next-generation mobile networks.
We are looking for SW Engineers who want to work with us to increase our customers' satisfaction with 5G Baseband SW as well as to develop a new 6G RAN technology. Here you get opportunity to work alongside experience developers to learn how Ericsson system is designed, implemented, tested and integrated.
This is a great opportunity for those of you who are eager to learn, adaptable, like solving technical problems and really enjoy collaborating.

What you will do:
- Develop and maintain Ericsson's Purpose Build RAN Layer 1 Baseband software
- Develop a new generation of RAN SW (6G)
- Use AI-assisted engineering tools to support your activities like developing code, test creation, debugging, documentation, and code review
- Learn how 5G/6G radio systems and physical layer processing work
- Participate in feature development, debugging, testing, code reviews, and continuous integration activities
- Collaborate with software developers, architects, system engineers, and testers across global teams
- Work with software quality, test coverage, maintainability, and continuous improvement
- Explore and contribute to AI/ML-enabled features that may be implemented in the product
- Grow your technical skills through mentorship, feedback, and hands-on experience

The skills you bring:
- A recently completed, or soon to be completed, BSc or MSc degree in Computer Science, Electrical Engineering, Engineering Physics, Embedded Systems, Telecommunications, or a related discipline
- Programming experience in C/C++, Python
- Foundational understanding of AI and machine learning concepts
- Practical experience using Python for data processing, experimentation, or machine learning through university coursework, thesis work, or personal projects
- Ability to use AI-assisted development tools critically and responsibly
- Strong analytical and problem-solving skills
- Interest in software engineering, high-performance systems, and telecommunications
- Good communication skills in English
