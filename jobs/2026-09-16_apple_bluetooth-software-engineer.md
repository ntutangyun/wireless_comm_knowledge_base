# Bluetooth Software Engineer

**Apple** · Cupertino · req `200683018`

## Summary

Join our Wireless Software Engineering team and drive innovation that matters! We craft and seamlessly integrate technologies that enrich people's lives such as exposure notifications for covid-19, audio, gaming, fitness, and more; all while delivering the best user-experience. If you're a strong software engineer and are passionate about building awesome Bluetooth solutions, we may have the job for you. The Core Bluetooth team is looking for a motivated software engineer to design, implement, and maintain next generation personal connectivity solutions. You are responsible for crafting and developing world changing wireless protocols such as exposure notifications on the very latest Apple products.

## Description

You will be challenged with unique problems: building and developing software solutions to enrich the Apple ecosystem for current and next generation products.

## Minimum Qualifications

- Bachelors Degree in Computer Science, Computer Engineering, Electrical Engineering, or equivalent experience
- Strong C++, C, or Objective-C software skills

## Preferred Qualifications

- Wireless communications system experience is a plus (especially Bluetooth!)
- Experience in building user level applications, public frameworks, audio, or AR/VR solutions is a plus
- Ability to write clean, maintainable code in an OS/RTOS environment
- Proficiency in using AI-based software development tools
