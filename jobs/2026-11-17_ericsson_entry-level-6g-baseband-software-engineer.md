# Entry Level: 6G Baseband Software Engineer

About this opportunity
Forty percent of the world's mobile traffic is carried over Ericsson networks. Nobody thinks about that until it stops. A mobile network is how people call an ambulance, pay for lunch or find each other - invisible when it works, national news when it fails. That is the scale that a single line of our baseband code operates on. We are now entering the 6G program, building it in Lund as a product heading for its first release. This is not a research demo, not a paper, but software that ships to the end user for real world applications. Decisions around how 6G technology operates are still open to explore. A radio has a fixed amount of time, spectrum and processing to spend, and it now has much more than one job to execute.

What you will do
You will join a cross-functional team working in baseband software development: in the physical layer, where radio energy becomes data, and in the Layer 2 uplink and downlink processing chains that schedule and move user data. The difficulty is real, and it is specific. Real-time C and C++ under microsecond deadlines, against 3GPP specifications, on multi-core DSPs, is unforgiving work. The same capability must also hold on two very different machines: Ericsson's own many-core baseband hardware, and standard commercial servers. What is cheap on one is expensive on the other. Making a single design work on both is an open problem here, not a solved one you would be maintaining. We treat working with AI as an engineering skill to be learned rather than a tool to be handed out, and the scarce part of that skill is judgment: knowing which answer to trust, which to verify, and which to throw away is key.

The craft itself is classic baseband engineering, and it looks like this:
- Take a feature from a question to shipped code - studies, systemization, design, implementation, test.
- Read the 3GPP specification behind it and turn that into something a radio can actually meet.
- Rework parts of a baseband that has shipped to hundreds of networks so that it carries 6G, without breaking what runs today.
- Work against a standard that is still moving, and feed what you learn back into it.
- Explore parts of a C++ code base far larger than anything at any university and find the three lines that matter.
- Test it, improve the test environment you need in order to test it, and hunt the bugs that only appear on real hardware.

The skills you bring
An MSc in computer science, electrical engineering, engineering physics, wireless communication or similar. C or C++ close to the hardware, and enough mathematics to be unafraid of a signal.
